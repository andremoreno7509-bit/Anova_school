# A-NOVA Fase 3.2 — Portal de Padres/Tutores (v0.3.1)

- Rol TUTOR integrado al inicio de sesión y navegación.
- Administración puede crear cuentas Tutor desde Usuarios.
- Nuevo módulo Tutores para vincular Tutor ↔ Alumno.
- Un tutor puede tener uno o varios alumnos vinculados.
- Un alumno puede tener más de un tutor.
- El backend valida cada vínculo antes de exponer información académica.
- Dashboard familiar: promedio, asistencia, tareas pendientes, incidencias y Academic Pulse.
- Consulta de calificaciones, asistencia, tareas, horario y reportes por alumno.
- El portal del tutor es de solo lectura; no modifica información académica.
