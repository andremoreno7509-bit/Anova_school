# A-NOVA Fase 2.4 — Portal del Alumno dinámico

Versión 0.2.3.

- Dashboard del alumno calculado desde PostgreSQL/Prisma.
- Promedio real a partir de calificaciones publicadas.
- Porcentaje de asistencia y faltas reales.
- Tareas activas y próxima entrega.
- Academic Pulse calculado con rendimiento, asistencia y carga de tareas.
- Vistas reales de materias, calificaciones, tareas, asistencia y perfil.
- El API utiliza la sesión autenticada: cada alumno consulta exclusivamente su propia información.

Nota: todavía no existe entrega de tareas por alumno, por lo que “tareas activas” representa actividades publicadas y vigentes, no entregas individuales pendientes.
